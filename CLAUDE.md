# CafeBot – Permanent Project Instructions

- Read existing files before making changes.
- Work on one task or feature at a time.
- Modify only files necessary for the current task.
- Never rewrite unrelated files.
- Keep code simple, readable, and beginner-friendly.
- Verify and test every change before proceeding.
- Never hardcode API keys, passwords, or secrets.
- Use environment variables for sensitive configuration.
- Avoid unnecessary dependencies.
- Follow a token-efficient development approach.
- Preserve existing working functionality.
- Explain important changes briefly.

## Project rules
- Products, prices, ingredients and availability come ONLY from data/menu.json. Never invent them.
- Never save an order as confirmed without explicit customer confirmation.
- Current scope: chat UI with mock replies. No AI API, database, auth or backend yet.
